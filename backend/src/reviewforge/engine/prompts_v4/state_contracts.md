### Shared state paths

State navigation is a bounded location index, not evidence or an exhaustive writer set.
For a state/configuration/timing claim, follow the observed reader to relevant configuration,
initialization and reset paths, then establish their callers and order on the claimed input.
Inspect alternative indexed producers rather than treating a method named init as the only writer.
A registration annotation or a configuration call alone proves neither CLI value binding nor
execution before the changed command. Read the resolver and actual entry path when those facts
decide the claim. Cite saved observations for the binding and order; missing proof stays UNKNOWN.
